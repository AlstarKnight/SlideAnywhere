# SlideX

SlideX 是一个 Android 全局侧边面板：在任何界面，从屏幕边缘一滑或点一下悬浮图标，就能打开一块多页卡片面板，里面放常用应用、快捷操作、开关、便签、小部件和系统信息。

它复刻的是已停更的应用「全局负一屏」，用 Kotlin 和 Jetpack Compose 重新编写，适配新版 Android（最低 Android 8.0，目标 Android 16）。

## 功能

**打开面板**

- 边缘触发条：左侧或右侧，可调位置、高度和宽度，可隐藏；自动避开系统返回手势；长按后可直接拖动换位置
- 悬浮图标：圆形或方形，可调大小和不透明度，可拖到屏幕任意位置；点击和长按可分别设为打开面板或任意快捷操作；弹出键盘时自动避开
- 快捷设置磁贴和桌面快捷方式（也可以长按 SlideX 的桌面图标选「打开面板」）
- 从触发条往里拉，面板跟着手指滑出（默认开启，可在「触发设置 → 区域 → 面板跟手滑出」关闭）
- 常驻通知也能打开面板（通知可以关掉）
- 点面板外的空白处或按返回键关闭

**卡片**

- 多页面板，每页可放多张卡片；所有编辑都直接在面板里完成，不用进设置
- 点面板顶部的 ✏ 编辑当前页：增删和拖动卡片、添加页面，以及这一页的外观（主题、背景图片、透明度）
- 长按某张卡片的标题，单独编辑这一张卡片，包括是否显示标题
- 编辑模式下长按图标拖动排序，按住卡片的 ≡ 拖动调整卡片顺序；点图标可以改名
- 添加时可以多选，一次加好几个应用或快捷操作
- 图标卡片：应用、快捷方式、网址或任意 URI 可以混放，每行 2 到 6 个，可以只显示图标
- 链接入口：添加时可以直接选其他应用里的页面，上方的搜索框支持名称、拼音和首字母
  - 常用入口：支付宝扫一扫和付款码，微信、美团、飞书的扫一扫
  - 更多入口：支付宝的收款码、乘车码、转账、蚂蚁森林，云闪付扫一扫和付款码，微博扫一扫和发微博，以及京东、淘宝、QQ、哈啰、钉钉、哔哩哔哩的扫一扫。部分链接来自公开的 Scheme 列表，没有在每个应用版本上验证过
  - 应用自己的长按快捷方式（静态声明的那部分）也会列出来，点一下就能打开；动态快捷方式只有默认桌面能读取，列不出来
  - 微信付款码、抖音扫一扫没有可用的公开入口，所以没有提供
- 图标间距：图标卡片和常用应用卡片可以调上下间距（0 到 40dp）和左右间距（自动，或 0 到 64dp，图标会跟着缩放）
- 文字卡片：可调字号、粗体、斜体、居中和颜色，可选卡片背景，高度自动或固定
- 便签卡片（高度可固定）
- 一言卡片：在编辑模式里添加，点一下换一句
- 最近使用、常用应用卡片
- 系统小部件卡片：把其他应用的桌面小部件放进面板，高度可固定；选小部件时可以按应用名或小部件名搜索（支持拼音、首字母）
- 系统卡片：电量（含温度、电压、健康）、亮度条、音量条（媒体、铃声、闹钟）、内存与存储（含开机时长）；拖动亮度条时面板变透明，方便看实际效果

**快捷操作和开关**

- 快捷操作：通知栏、快捷设置、最近任务、主屏幕、返回、锁屏、截屏、分屏、电源菜单、播放/暂停、上一首、下一首、音量加减、语音助手、应用抽屉、相机、相册、拨号、系统设置
- 开关（图标显示当前状态）：手电筒、自动旋转、自动亮度、屏幕常亮、护眼、静音、震动可以直接切换；WLAN、蓝牙、移动数据、热点、定位、NFC、飞行模式会打开系统的开关面板（Android 10 起普通应用不能直接切换这些）

**个性化**

- 主题预设：星空、Material（Android 12+ 跟随壁纸取色）、纸感、经典；深浅色可跟随系统
- 面板背景模糊（Android 12+），背景遮罩深浅可调
- 页面外观（在面板里点 ✏ 设置）：每页可以单独设主题预设和深浅色；可设背景图片（卡片滚动时背景不动，可选铺满、横向填充或拉伸），背景和卡片透明度可调
- 图标包（Nova / ADW 格式）
- 黑名单或白名单：黑名单在选定的应用里隐藏触发条和悬浮图标，白名单只在选定的应用里显示（可以选桌面）；横屏时也可以隐藏
- 应用模糊搜索：可按名称、拼音、拼音首字母或包名查找，比如输入 wx 就能找到微信（拼音搜索需 Android 10+）
- 配置导入导出（JSON）

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 悬浮窗 | 显示触发条、悬浮图标和面板，必须开启 |
| 通知 | 显示保持服务运行的常驻通知 |
| 忽略电池优化、开机自启 | 防止后台被系统杀掉，开机后自动恢复 |
| 无障碍服务 | 锁屏、截屏、通知栏、最近任务、分屏、电源菜单等系统操作；识别当前应用，用于黑名单和白名单；查看窗口列表找到输入法的位置，让悬浮图标避开键盘。只看窗口的类型和位置，不读取屏幕上的文字和内容 |
| 使用情况访问 | 最近使用和常用应用卡片 |
| 修改系统设置 | 自动旋转、亮度、自动亮度等开关 |
| 勿扰权限 | 切换静音模式 |
| 查询所有应用 | 列出已安装的应用，供添加到面板 |
| 网络 | 只给一言卡片用，从 hitokoto.cn 获取句子 |

SlideX 不收集任何数据。只有一言卡片会联网，从 hitokoto.cn 获取句子，不用一言卡片就不会联网。

首次打开后在「权限管理」里开启「悬浮窗」，再打开首页的「启用全局负一屏」开关即可使用。其余设置分在「触发设置」「主题外观」「高级设置」「配置管理」里。Android 13 及以上侧载安装的应用，开启无障碍服务前要先在系统的应用信息页右上角菜单里选「允许受限设置」。

## 编译

仓库的 GitHub Actions 会在每个 PR 和每次推送到 main 时运行单元测试、lint，并编译 APK：

- 配置了签名密钥时，生成固定签名的发布版，并更新上面的下载链接。需要在仓库 Secrets 里配置 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`
- 调试版 APK 可以在对应的 Actions 运行页面下载，每次签名都不同，升级前要先卸载旧版

本地编译需要 JDK 17 和 Android SDK（compileSdk 36）：

```
./gradlew testDebugUnitTest assembleDebug
```
